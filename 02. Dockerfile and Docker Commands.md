   - A container is a process created from a Docker image.

## 2. Questions

**Q1. Can the `docker run` command pull an image?**

Yes. If the image is not available locally, it pulls the image from the Docker registry.

```bash
docker run hello-world
```

**Q2. How do you list Docker images locally?**

```bash
sudo docker images
# or
sudo docker image ls
```

**Q3. What are the steps to create a Docker image (theory)?**

- A Docker image is created from a Dockerfile.
- We can write our own Dockerfile.
- Otherwise, we can pull (download) images from a Docker registry.

```bash
docker run hello-world
```

## 3. Linux OS Flavors

Examples: CentOS, Ubuntu, Fedora, Mint, SUSE, Debian, Kali, Arch Linux, Rocky Linux, Amazon Linux, AlmaLinux, Zorin OS, AIX, Oracle Linux, etc.

> **Note:** In production environments, avoid using a full, heavy OS unnecessarily.

## 4. Docker-Specific Lightweight Images

1. **BusyBox image**
   - Used for simple tasks such as printing messages.
   ```bash
   docker run hello-world
   ```

2. **Alpine image**
   - Used for:
     - Web servers
     - Python
     - Java
     - MySQL
     - Prometheus
     - Nagios
   - Lightweight and secure.

## 6. Interview Concept

**Traditional approach:**

1. Install the OS (CentOS).
2. Install the web server:
   ```bash
   yum install httpd
   ```
3. Start the service:
   ```bash
   systemctl start httpd
   ```

**Docker approach:**

1. Write a Dockerfile.
2. Build a Docker image.
3. Run a Docker container (process).

## 7. Docker Registry

- The Docker registry is **Docker Hub**.
- It is used to store and download images.

## 8. Important Docker Commands

| Task | Command |
|---|---|
| Pull an image | `sudo docker pull hello-world` |
| List images | `docker images` / `sudo docker images` |
| List running containers | `sudo docker ps` |
| List all containers (including stopped) | `sudo docker ps -a` |
| Run a container | `sudo docker run hello-world` |
| Run a container with a name | `sudo docker run --name myfirstcon hello-world` |
| Remove a container | `sudo docker rm 2a0c073ec397` |
| Run and auto-remove a container | `docker run --rm --name myhello hello-world` |

# 15. Docker Compose Hands-On

## Running with Variables (Without Compose)

```bash
MY_ENV=prod
docker build -t my_node_app:$MY_ENV --target $MY_ENV .
MY_PORT=8001
```
Path: `/root/docker/lect-16/src`

```bash
docker run --name my_prod -p 8010:$MY_PORT -e PORT=$MY_PORT -v /root/docker/lect-16/src:/app/src my_node_app:$MY_ENV
```

## Installing Docker Compose

```bash
sudo curl -L "https://github.com/docker/compose/releases/download/1.29.2/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose

sudo chmod +x /usr/local/bin/docker-compose

sudo ln -s /usr/local/bin/docker-compose /usr/bin/docker-compose

docker-compose --version
/usr/local/bin/docker-compose --version
```

## Compose File (Using an Existing Image)

**`docker-compose.yml`**
```yaml
services:
  my-app:
    image: my_node_app:${MY_ENV}
    ports:
      - "${MY_PORT}:${MY_PORT}"
    volumes:
      - ./src:/app/src
    environment:
      PORT: ${MY_PORT}
```

**`.env`**
```
MY_PORT=8000
MY_ENV=dev
```

```bash
docker-compose up
docker-compose ps
```

> **Note:** Always navigate to the directory containing the `docker-compose.yml` file before running these commands.

```console
root@ahmadhassan:~/docker/lect-17/docker-compose# docker-compose ps
Name                        Command               State                    Ports
-----------------------------------------------------------------------------------------------------------
docker-compose_my-app_1   docker-entrypoint.sh /bin/ ...   Up      0.0.0.0:8010->8000/tcp,:::8010->8000/tcp
```

- Name: `docker-compose_my-app_1`
- Naming syntax: `<compose-directory-name>_<service-name>_<service-count>`

```bash
docker-compose down
docker-compose up -d
```

## Compose File (Building the Image)

**`docker-compose.yml`**
```yaml
services:
  my-app:
    build:
      context: .
      target: ${MY_ENV}
    image: my_node_app:${MY_ENV}
    ports:
      - "${MY_PORT}:${MY_PORT}"
    volumes:
      - ./src:/app/src
    environment:
      PORT: ${MY_PORT}
```

```bash
docker build -t ahmadimage .
```

**`Dockerfile`**
```dockerfile
FROM node:15-alpine as prod
ARG PORT=8000
ENV PORT=$PORT
WORKDIR app
copy src src
copy package.json .
RUN npm install --only=prod
EXPOSE $PORT
CMD npm run start:prod
FROM prod as dev
RUN npm install --only=dev
CMD npm start
```

# 27. Docker Networking Hands-On

## Setting Up Containers

1. **Start containers in detached mode with a terminal:**
   ```bash
   docker run -dit --name alpine1 alpine ash
   docker run -dit --name alpine2 alpine ash
   ```
   These containers are automatically assigned IPs in the default network:
   - `alpine1`: 172.17.0.2
   - `alpine2`: 172.17.0.3

2. **Check running containers:**
   ```bash
   docker ps
   ```

3. **Inspect container details:**
   ```bash
   docker inspect alpine1
   docker inspect alpine2
   ```

4. **Access a container's shell:**
   ```bash
   docker exec -it alpine1 ash
   ```

## Creating a Custom Network

1. **Create a custom bridge network:**
   ```bash
   docker network create --driver bridge myahmad
   ```

2. **Run containers in the custom network:**
   ```bash
   docker run -dit --name alpine1 --network myahmad alpine ash
   docker run -dit --name alpine2 --network myahmad alpine ash
   docker run -dit --name alpine3 --network myahmad alpine ash
   ```
   Example IPs in the `myahmad` network:
   - `alpine1`: 172.21.0.2
   - `alpine2`: 172.21.0.3
   - `alpine3`: 172.21.0.4

3. **Verify networking with `ping`** — from `alpine1`, check connectivity to `alpine2`:
   ```bash
   docker exec -it alpine1 ash
   ping 172.21.0.3
   ```
   Successful pings confirm that the containers can communicate within the `myahmad` network.

## Connecting a Container to Multiple Networks

1. **Run a container in the default network:**
   ```bash
   docker run -dit --name alpine4 alpine ash
   ```
   `alpine4` gets the IP `172.17.0.2`.

2. **Connect `alpine4` to the custom network:**
   ```bash
   docker network connect myahmad alpine4
   ```
   `alpine4` now has IPs in both networks:
   - Default: 172.17.0.2
   - `myahmad`: 172.21.0.5

3. **Verify connectivity** — from `alpine4`, ping another container in the `myahmad` network (e.g. `alpine1`):
   ```bash
   docker exec -it alpine4 ash
   ping 172.21.0.2
   ```

## Using Host Network Mode

```bash
docker run -dit --name alpine5 --network host alpine ash
```
This shares the host's network stack, so the container has no separate IP.

## Disconnecting a Container from a Network

```bash
docker network disconnect myahmad alpine4
```
After this, `alpine4` no longer has an IP in the `myahmad` network.

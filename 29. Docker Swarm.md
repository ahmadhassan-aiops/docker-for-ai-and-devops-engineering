# 29. Docker Swarm

**Docker Swarm** is a container orchestration tool that manages multiple containers with high availability (HA).

**Cluster** → manages multiple nodes; a collection of nodes.

You need 2 machines: EC2, containers, OVM, VMware or any hypervisor.

| Hostname | IP | Role |
|---|---|---|
| `ahmadhassan` | 192.168.1.8 | Master |
| `ahmadnode1` | 192.168.1.9 | Worker |

- Port: **2377**
- On AWS EC2, this port must be opened (a network-engineer task).

## Initialising the Swarm (Master: 192.168.1.8)

```bash
docker swarm init --advertise-addr 192.168.1.8
# or
docker swarm init
```

```console
Swarm initialized: current node (y9u7aje8kuvruaeekyzbd957t) is now a manager.

To add a worker to this swarm, run the following command:

docker swarm join --token <worker-join-token> 192.168.1.8:2377

To add a manager to this swarm, run 'docker swarm join-token manager' and follow the instructions.
```

```bash
docker node ls
```

## Joining the Worker (192.168.1.9)

```bash
docker swarm join --token <worker-join-token> 192.168.1.8:2377
```

## Creating a Service (Master)

```bash
docker network create -d overlay mynetwork
docker build -t ahmad/web:swarm .
```

- Dockerfile → Docker image → Docker **container**
- Dockerfile → Docker image → Docker **service**

```bash
docker service create --name web-swarm --publish 8080:80 ahmad/web:swarm

docker service ls
docker ps

docker exec -it webapp1.1.wreyruyperfzolc1vg2wy6abd bash
docker service ps rw1f4yi7bz30
docker node update --availability drain ahmadhassan
```

Browser → `http://192.168.1.9:8001/`

```bash
docker node update --availability active ahmadhassan
docker node ls
docker service rm webapp1
docker service create --name webapp1 -d --network mynetwork --replicas=2 -p 8001:80 ahmad/web:swarm
```

## Pushing the Code to GitHub

1. Create a GitHub token.
2. Download and install Git Bash.
3. Extract your code on your local machine, then run:

```bash
git init
git add .
git config --global user.email "ahmad.hds393@gmail.com"
git config --global user.name "786AHMADHASSAN"
git commit -m "Fresh code"
git push
```

Your files will now appear in your GitHub repository.

# 34. Archiving Images and Containers

- Docker image → Docker container → runs as a process → we can run our application.
- Container → commit → Docker image → container.
- Docker image → Docker container → archive (tar) → another machine → extract → create a container.

The four commands: **docker export → docker import → docker save → docker load**

```bash
docker --help | grep -E "(export|import|load|save)"
```

## Save and Load (Images)

**`Dockerfile`**
```dockerfile
FROM busybox
CMD echo $((40+2))
```

```bash
docker build -t maths .
docker run maths
```

```bash
docker save maths > maths.tar
```
`docker save` packs a Docker image into a tar file.

```bash
scp -vr maths.tar ahmad@192.168.1.9:/home/ahmad
```

**On the node machine:**
```bash
docker import maths.tar maths
```
You will get an error.

- `docker save` → creates the tar file.
- `docker import` → can extract the tar file but cannot create a container from it (wrong step).

```bash
docker load < maths.tar
docker run maths
```

**Summary:**
- Multiple Docker images can be saved together.
- `docker save` → creates a tar file of Docker images.
- `docker import` → can extract the tar file but cannot create a container (wrong step).
- `docker load` → loads a Docker image from a tar file.
- Finally, `docker run` creates a container from the Docker image.

## Export and Import (Containers)

The `export` command works on **containers**:

```bash
docker export 903129ad58af > hello.tar
```

Docker image → Docker container:

```bash
docker import calc1.tar calcfs:latest
docker run -t -i calcfs /bin/sh
```

## Quick Reference

| Commands | Work on |
|---|---|
| `save` → `load` | Images |
| `export` → `import` | Containers |

**DinD (Docker in Docker)** → Docker installed inside Docker.

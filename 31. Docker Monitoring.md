# 31. Docker Monitoring

We use the **ctop** command to monitor Docker containers.

Project: https://github.com/bcicen/ctop

ctop can be installed in two ways:
1. Run ctop through Docker.
2. Install it with `wget` and the package repository.

## Option 1: Run via Docker

```bash
docker run --rm -ti \
--name=ctop \
--volume /var/run/docker.sock:/var/run/docker.sock:ro \
quay.io/vektorlab/ctop:latest
```

## Option 2: Install the Package

```bash
echo "deb http://packages.azlux.fr/debian/ buster main" | sudo tee /etc/apt/sources.list.d/azlux.list
wget -qO - https://azlux.fr/repo.gpg.key | sudo apt-key add -
sudo apt update
sudo apt install docker-ctop
```

## Another Monitoring Tool

```bash
docker stats
```

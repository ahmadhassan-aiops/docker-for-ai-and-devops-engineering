# 32. Docker Secrets, Docker Stack and JBoss Deployment

## What Is a Secret?

A secret is a very important asset — if it is breached, we will be in trouble. Examples: passwords, SSL keys, certificates, client tokens, payment tokens, PIN codes and CVVs. Storing secrets safely is very important.

## What Is a Docker Secret?

A secret is a blob of data that should not be transmitted over a network or stored unencrypted in a Dockerfile or in your application source code. Example: a username and password.

**`.env` file:**
```
username : ahmad
password : ahmad123
```

> Docker secrets work only with **Docker Swarm**.

You need 2 machines in your lab:
1. Master
2. Node

Set up Docker Swarm before this practical — refer to topic 29.

## Creating a Secret

```bash
echo "This is secret" | docker secret create my_secret_data -
```

```console
root@ahmadhassan:~# docker secret ls
ID                          NAME             DRIVER    CREATED              UPDATED
tgwbyycv2c1iqozqkyke86kjh   my_secret_data             About a minute ago   About a minute ago
```

## Using the Secret in a Service

```bash
docker service create --name="redis" --secret="my_secret_data" redis:alpine
```

- Default secret location: `/run/secrets/<secret-name>` (inside the container, not on your host machine).
- The unencrypted secret is mounted into the container in an in-memory file system at `/run/secrets`.

```bash
docker service --help
docker service ls
docker service ps dfmgumsl5g29

docker exec -it b2ed500654dd sh

docker ps --filter name=redis -q

docker exec $(docker ps --filter name=redis -q) cat /run/secrets/my_secret_data
```

**Remove the secret from the service (master):**
```bash
docker service update --secret-rm="my_secret_data" redis
```

# 33. Docker Aliases

**What is an alias?**
An alternative name you can give to a command.

Example: `rm` → delete

```bash
alias a="ls -ltrh"
a
```

## Formatted `docker ps`

```bash
docker ps --format '{{.ID}} ~ {{.Names}} ~ {{.Status}} ~ {{.Image}}'

alias dkps="docker ps --format '{{.ID}} ~ {{.Names}} ~ {{.Status}} ~ {{.Image}}'"
```

## Formatted `docker stats`

```bash
docker stats --format "table {{.Name}}\t{{.CPUPerc}}\t{{.MemUsage}}\t{{.NetIO}}"

alias dkt="docker stats --format 'table {{.Name}}\t{{.CPUPerc}}\t{{.MemUsage}}\t{{.NetIO}}'"
```

## More Aliases

```bash
alias dki="docker images"
alias dkclean="docker ps -a -f status=exited"

alias dkclean="docker rm $(docker ps -q -a -f status=exited)"
```

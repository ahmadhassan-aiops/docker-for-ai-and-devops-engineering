# 05. Docker Pull and Push Commands

## 1. Pull vs Push

### Docker pull

Downloads an image from a Docker registry (Docker Hub) to the local machine.

```bash
docker pull hello-world
```
→ Downloads the `hello-world` image.

### Docker push

Uploads a local image to a Docker registry (Docker Hub).

1. Before pushing an image, log in to Docker Hub from your machine:
   ```bash
   docker login
   ```
   Enter the code that appears after running `docker login`.

2. Rename (tag) the image with your Docker Hub username so that it can be pushed to Docker Hub:
   ```bash
   docker tag <old-image-name:tag> <dockerhub-username>/<new-image-name:tag>
   ```

3. Push the image:
   ```bash
   docker push <new-image-name:tag>
   ```

## 2. Simple Understanding

- **Pull** = download
- **Push** = upload

## 3. Docker Push Command

```bash
docker push <image-name>
```
- Uploads the specified image to Docker Hub.

## 4. Tag Concept (Renaming an Image)

- A tag is used to rename an image or give it a new name.
- Tagging is required before pushing an image to Docker Hub.

```bash
docker tag <old-image-name:tag> <dockerhub-username>/<new-image-name:tag>
```

## 5. Example

**Check images:**
```bash
docker images
```

Sample output:
```console
myimage    v2    37eb1fb17a1c    2 days ago    5.57MB
```

**Tag the image:**
```bash
docker tag myimage:v2 username/new_image_name:latest
```

- `myimage:v2` → existing image
- `username` → Docker Hub username
- `new_image_name:latest` → new image name with tag

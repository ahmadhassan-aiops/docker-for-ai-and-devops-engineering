## Detaching from a Container

`Ctrl + P + Q` → leaves the container while its process keeps running in the background.

## HTML Page Mounted into an Nginx Container

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<meta http-equiv="X-UA-Compatible" content="IE=edge">
<title>Welcome</title>
<meta name="viewport" content="width=device-width, initialscale=1">
</head>
<body>
<h1>Welcome!</h1>
<p>This file has been created on the host machine and has been
mounted into the Nginx Docker Container!</p>
</body>
</html>
```

## `docker run` vs `docker exec`

- If you start a container with `docker run` and then type `exit` inside it, the container stops.
- If you enter an already running container with `docker exec` and then press `Ctrl + C` or type `exit`, the container keeps running.

## Daemonized Container

```bash
docker run --name my_daemonized -d ubuntu /bin/sh -c "while true; do echo my daemonized container; sleep 1; done "
```

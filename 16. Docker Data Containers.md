# 16. Docker Data Containers

## Storage Recap

| Storage type | Where data lives |
|---|---|
| Docker volume | Docker area |
| Bind mount | File system |
| tmpfs | RAM |

- Container 1 → Data 1
- Container 2 → Data 2

In topic 12, using the same directory name creates the directory, but you cannot access existing data from another container. A **data container** solves this.

## Creating a Data Container and Sharing It

```bash
docker create -v /dbdata --name dbstore postgres:latest /bin/true
docker run -d --volumes-from dbstore --name db1 -e POSTGRES_PASSWORD=mysecretpassword postgres:latest
```

`dbdata` → `db1`

```bash
docker exec -it db1 /bin/sh
```

`dbdata` → `db2`

```bash
docker run -d --volumes-from dbstore --name db2 -e POSTGRES_PASSWORD=mysecretpassword postgres:latest
docker exec -it db2 /bin/sh
```

Both containers use the same volume path:
```
/var/lib/docker/volumes/787b8d2e1049eeb6cf9be2af628b8118548cc8c9c6d140c1e8424d27ccedc84a/_data
/var/lib/docker/volumes/787b8d2e1049eeb6cf9be2af628b8118548cc8c9c6d140c1e8424d27ccedc84a/_data
```

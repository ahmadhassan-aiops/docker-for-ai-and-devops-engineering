# 20. Deploying a Docker App to AWS ECS

- **ECS**: Elastic Container Service
- **ECR**: Elastic Container Registry

ECS is the best AWS service for Docker, and it is AWS's dedicated service for Docker.

| | Building blocks |
|---|---|
| **Docker** | Dockerfile, Docker image, container, networking, volumes, running multiple containers with Docker Compose |
| **ECS** | Cluster, task definition, services, container |
| **Google** | Does the same work, but the method is different |

## Related AWS Services

| Service | Purpose |
|---|---|
| EC2 | A server (machine) we can create |
| VPC (Virtual Private Cloud) | Takes care of networking only |
| ELB | Elastic Load Balancer |
| IAM role | Create users and assign them a role for a specific service or admin privileges |
| Security group | Ports, exposing and accessing services |
| Auto Scaling | |

**Cluster** → more than one node, with load balancing across the different nodes.

Image: `<aws-account-id>.dkr.ecr.us-east-1.amazonaws.com/mynode:v1`

## Load Balancer Types in AWS

1. Network Load Balancer
2. Classic Load Balancer
3. Application Load Balancer

Docker user → Linux base OS → Docker host → container runs

## ECS Launch Types

1. **EC2**: ECS runs on EC2 servers.
2. **Fargate**: runs containers without managing the host; you cannot troubleshoot at the container level.

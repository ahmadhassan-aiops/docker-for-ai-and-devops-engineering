# 28. Linking Two Containers

- **Docker linking** → connects 2 containers.
- **Custom network** → connects containers (see topic 27).

## Publishing Ports

```bash
docker run -d -P training/webapp python app.py
docker run -d -p 8000-9000:5000 training/webapp python app.py
docker run -d -p 127.0.0.1:8001:5001 training/webapp python app.py
docker run -d -p 127.0.0.1::5000 training/webapp python app.py
docker port 2a261088829a
```

## Clean Up

```bash
docker kill $(docker ps -q)
docker rm $(docker ps -a -q)
```

## Linking a Web App to a Database

```bash
docker run -d --name db training/postgres

docker run -d -P --name web --link db:db training/webapp python app.py
```

Syntax: `--link <name or ID>:<alias>`

```bash
docker inspect -f "{{ .HostConfig.Links }}" web
```

Linked database IP: `172.17.0.2`

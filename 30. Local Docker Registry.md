# 30. Local Docker Registry

**What is a repository?**
A repository is like a warehouse: every package and image is stored in one place.

**Repositories covered so far:**
1. Docker Hub
2. GitHub
3. GitLab
4. ECR (AWS)

## Concept

Example: a company "ahmadhassan pvt ltd" with a domain registered through GoDaddy.

`ahmadhassan.com:8080` → `docker login`

```bash
docker pull ahmadhassan380/imagename:tag
docker pull ahmadhassan.com:8080/imagename
docker pull localrepo:8080/imagename

docker login
```

- The local registry's default port is **5000** (e.g. map it with `-p 5001:5000`).

```bash
docker push localrepository:port/imagename
```

## Practical

```bash
docker run -d -p 5000:5000 --restart=always --name registry registry:2
docker pull alpine

docker tag alpine ahmadhassan380/alpine
docker tag alpine localhost:5000/alpine
```

Documentation: https://docs.docker.com/registry/deploying/

```bash
docker exec -it containername sh
find / -name alpine    # inside the registry container
```

Default storage path: `/var/lib/registry`

## Registry with Docker Compose

**`docker-compose.yml`**
```yaml
version: '3'
services:
  registry:
    image: registry:2
    ports:
      - "5001:5000"
    environment:
      REGISTRY_STORAGE_FILESYSTEM_ROOTDIRECTORY: /data
    volumes:
      - ./data:/data
```

```bash
docker-compose up
docker ps
ls -ltrh /data
```

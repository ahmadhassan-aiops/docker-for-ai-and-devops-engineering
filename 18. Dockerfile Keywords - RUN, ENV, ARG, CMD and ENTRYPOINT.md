# 18. Dockerfile Keywords: RUN, ENV, ARG, CMD and ENTRYPOINT

## RUN

`docker run` turns an image into a container. Inside a Dockerfile, `RUN` executes Linux commands at build time, typically installations (`apt`, `yum`, `dnf`).

```dockerfile
RUN apt-get install git

RUN python script.py
```

**Question: Can the `RUN` instruction be replaced with another instruction?**
**Answer:** No.

**Method 1: separate instructions**
```dockerfile
RUN apt-get update
RUN apt-get install -y curl
RUN apt-get install httpd curl git update -y
```

**Method 2: combined into one instruction (only one intermediate layer)**
```dockerfile
RUN apt-get update && apt-get install -y curl && apt-get install -y git
RUN apt-get install git && apt-get install httpd && apt-get install curl
```

Both methods produce the same output.

## ENV

`ENV` defines a variable, and its value can be overridden at run time with `-e`:

```bash
docker run -e
```

```dockerfile
ENV ADMIN_USER="mark"
RUN echo $ADMIN_USER > ./mark
```

```bash
docker run --rm test sh -c 'echo $ADMIN_USER'

docker run --name mycont --rm -d test sh -c 'echo $ADMIN_USER'
docker run --name mycont1 -d test sh -c 'echo $ADMIN_USER'
```

**Version 1: 4 layers**
```dockerfile
FROM alpine
ENV ADMIN_USER="mark"
RUN echo $ADMIN_USER > ./mark
RUN unset ADMIN_USER
```
We still see `mark` in the output because of the `echo` line, even though the variable is unset afterwards.

**Version 2: 3 layers**
```dockerfile
FROM alpine
RUN export ADMIN_USER="mark" && echo $ADMIN_USER > ./mark && unset ADMIN_USER
CMD sh
```
Here we do not see `mark` in the output, because the variable is unset within the same instruction.

```bash
docker run --rm test:v2
docker run --rm test:v2 sh -c 'echo $ADMIN_USER'
```

## Long-Running Container

```bash
docker run --name my_cont1 -d alpine /bin/ash -c "while true; do echo Ahmad Hassan; sleep 1; done"
```

## Restart Policies

```bash
docker run -p 8000:80 --restart always nginx
docker run --name testing -p 8001:80 nginx
docker run --name testing2 -p 8002:80 --restart=on-failure:3 nginx
```

## ARG

```dockerfile
FROM alpine
# Define a build argument with a default value
ARG var_name=def_value

# Use the ARG value in a RUN command
RUN echo ${var_name}

# Set an environment variable
ENV foo=other
ENV bar=${var_name}
```

```bash
docker build -t arg:v2 .
docker run -it --name myarg arg:v2
```

## CMD

```dockerfile
FROM busybox
CMD sleep 5
```
or in exec form:
```dockerfile
CMD ["sleep","5"]
```

```bash
docker build -t cmd:v1 .
docker run --rm --name test6 cmd:v1
docker run --rm --name test6 cmd:v1 sleep 10
docker run --rm --name test6 cmd:v1 top
```

```dockerfile
FROM busybox
#CMD sleep 5
CMD ["sleep","5"]
```

## ENTRYPOINT

```dockerfile
FROM busybox
#CMD sleep 5
#CMD ["sleep","5"]
ENTRYPOINT ["sleep"]
```

```bash
docker run --rm --name test6 cmd:v3 top
```

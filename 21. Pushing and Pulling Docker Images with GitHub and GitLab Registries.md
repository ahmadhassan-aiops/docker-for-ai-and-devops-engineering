# 21. Pushing and Pulling Docker Images with GitHub and GitLab Registries

Registries covered so far:
- AWS → ECR (Elastic Container Registry)
- GitLab
- GitHub

## GitLab Container Registry

Create an access token: **Profile → Preferences → Access Tokens → New token**

```
<gitlab-personal-access-token>
```

```bash
docker login registry.gitlab.com
docker tag <old image name> <new image name or location>
docker tag alpine:latest registry.gitlab.com/my519/dev:v1
docker pull registry.gitlab.com/my519/dev:v1
```

## GitHub Container Registry (GHCR)

Generate a personal access token (PAT): **Profile → Settings → Developer settings → Personal access tokens**

```bash
GIT_PAT=<github-personal-access-token>

echo $GIT_PAT | docker login ghcr.io -u 786AHMADHASSAN --password-stdin

docker tag <old image> <github-location/username/imagename>

docker tag busybox ghcr.io/786ahmadhassan/mybusybox:v1
docker push ghcr.io/786ahmadhassan/mybusybox:v1
```

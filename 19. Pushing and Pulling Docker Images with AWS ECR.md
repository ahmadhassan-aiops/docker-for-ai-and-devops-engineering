# 19. Pushing and Pulling Docker Images with AWS ECR

So far: Docker Hub → images are pushed and pulled from the command line.

## 1. Cloud Container Registries

Public cloud providers (AWS, Google and Azure) each offer a container registry where Docker images are stored:

| Provider | Registry |
|---|---|
| AWS | ECR (Elastic Container Registry) |
| Google | GCR (Google Container Registry) |
| Azure | ACR (Azure Container Registry) |

## 2. Version Control / Source Control / Code Repository

Version control is a place where the development team stores its code. Examples:

- GitHub
- GitLab (account verification requires a $1 card charge, which is refunded)
- Mercurial (Hg)
- SVN

## 3. AWS CLI Installation (Linux)

The AWS CLI is required to push and pull images to and from ECR.

Documentation: https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html

```bash
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install
aws --version
```

## 4. Create a Repository

First, create your own repository in ECR.

**Docker Hub push/pull format:**
```bash
docker push <dockerhub-username>/imagename
```
Example: `ahmadhassan380/ubuntu`

**AWS ECR format:**
```
<aws-account-id>.dkr.ecr.us-east-1.amazonaws.com/first_project
```
Tag example: `image:v1`

## 5. Credentials

> The secret access key is visible only once, when the IAM user is created.

Console sign-in URL: `https://<aws-account-id>.signin.aws.amazon.com/console`

```bash
export AWS_ACCESS_KEY_ID="************"
export AWS_SECRET_ACCESS_KEY="********************"
```

## 6. Tagging

| Registry | Command |
|---|---|
| Docker Hub | `docker tag myimage:v1 ahmadhassan380/myimage:v1` |
| AWS ECR | `docker tag first_project:latest <aws-account-id>.dkr.ecr.us-east-1.amazonaws.com/first_project:latest` |

Image name: `<aws-account-id>.dkr.ecr.us-east-1.amazonaws.com/first_project:latest`

## 7. Push Commands

```bash
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin <aws-account-id>.dkr.ecr.us-east-1.amazonaws.com

docker images

docker tag first_project:latest <aws-account-id>.dkr.ecr.us-east-1.amazonaws.com/first_project:latest

docker push <aws-account-id>.dkr.ecr.us-east-1.amazonaws.com/first_project:latest
```

## 8. Pull Command

```bash
docker pull <aws-account-id>.dkr.ecr.us-east-1.amazonaws.com/first_project:latest
```

# 13. Docker Image Variants and Changing the Default Docker Path

## Image Variants

```bash
docker pull node:14
docker pull node:15
docker pull node:14-slim
docker pull node:14-alpine
```

```console
root@ahmadhassan:~# docker image ls node
REPOSITORY   TAG         IMAGE ID       CREATED         SIZE
node         14          7d03025aad90   6 days ago      946MB
node         15-slim     dd6ccbd57bbd   10 months ago   160MB
node         15          3d3f41722daf   10 months ago   936MB
node         15-alpine   75631da67663   11 months ago   112MB
```

**1. Full image**
```console
node         15          3d3f41722daf   10 months ago   936MB
```
Total 946 MB = 10 MB data + 936 MB image

**2. Alpine image**
```console
node         15-alpine   75631da67663   11 months ago   112MB
```
112 MB image + 10 MB data = 122 MB image with data

Two types of lightweight image:
1. Alpine
2. BusyBox

Managing image size well is essential for a Docker admin or DevOps admin.

## Changing the Default Docker Path

- Default Docker path: `/var/lib/docker`
- Key file location: `/etc/docker/key.json`

1. Create the new directory:
   ```bash
   mkdir /home/docker
   ```

2. Stop Docker:
   ```bash
   systemctl stop docker.socket
   systemctl stop docker.service
   ```

3. Set the new data root in `/etc/docker/daemon.json`:
   ```bash
   vim /etc/docker/daemon.json
   ```
   ```json
   {
   "data-root": "/home/docker"
   }
   ```

4. Copy the existing data:
   ```bash
   cp -axT /var/lib/docker/ /home/docker/
   ```

5. Update the service file:
   ```bash
   vim /lib/systemd/system/docker.service
   ```
   ```ini
   ExecStart=/usr/bin/dockerd -H fd:// -g /home/docker --containerd=/run/containerd/containerd.sock
   ```

6. Reload and start Docker:
   ```bash
   systemctl daemon-reload
   systemctl start docker.service
   systemctl start docker.socket
   ```

Image ID path: `/home/docker/image/overlay2/imagedb/content/sha256`

```bash
systemctl status docker.service
```

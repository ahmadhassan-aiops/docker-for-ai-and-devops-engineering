# 03. BusyBox and Alpine Image Concepts

## 1. Docker Images: BusyBox and Alpine

- BusyBox and Alpine are lightweight Docker images.
- They are used for minimal environments and testing.

## 2. Basic Docker Commands

**Remove a container:**
```bash
docker rm <container-id>
```

**Remove an image:**
```bash
docker image rm <image-id/name>
docker rmi <image-id/name>
```

## 3. Docker Run Commands

```bash
docker run --name mycontainer busybox
```
- Creates a container from the BusyBox image.
- Assigns it the custom name `mycontainer`.

```bash
docker run --rm --name mycon1 busybox
```
- Creates and runs a container.
- Automatically removes the container after it finishes.
- It will not appear in `docker ps -a` (the stopped-containers list).

## 4. Running a Container in Interactive Mode

```bash
docker run -it --name container-name busybox /bin/sh
```

- `-it` → interactive terminal
- `/bin/sh` → opens a shell inside the container

**Commands inside the container:**

| Command | Purpose |
|---|---|
| `uname -a` | Display system information |
| `echo $SHELL` | Show the current shell |
| `touch samplefile` | Create a file |
| `exit` | Exit the container |

> **Note:** Files created inside the container are not available on the host OS. They exist only inside the container environment.

## 5. Listing Running Containers

```bash
docker ps
```
- Shows only running containers.

## 6. Working with Existing Containers

**Start a container:**
```bash
docker start containername
```

**Access a running container:**
```bash
docker exec -it container-name /bin/sh
```

> **Note:** `docker exec` lets you enter a running container. After you exit, the container keeps running.

## 7. Key Concepts

**Docker images**
- Images are read-only.
- They cannot be edited.

**Containers**
- Created from images.
- Act as running processes.
- Files can be modified inside containers.

**Reason:** a container adds an editable layer on top of the image.

## 8. Summary

**`docker run`**
- Creates a container from an image.
- Pulls the image from Docker Hub if it is not available locally.
- `-it` lets you enter the container.
- Exiting stops the container.

**`docker exec`**
- Used to enter a running container.
- Does not create a new container.
- The container keeps running after you exit.
